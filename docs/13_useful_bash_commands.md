# Useful Bash Commands

---

## Command reference

| Command | Description |
|---|---|
| `pwd` | Print working directory (i.e. the directory you are 'in') |
| `ls [-l]` | List files and subdirectories 'in' the working directory |
| `cd path/to/directory/` | Change directory to the listed directory path |
| `cd ..` | Move 'up'/'back' a directory |
| `cd -` | Return to the last directory path you were in |
| `cd ~` | Return to home directory (i.e. `/home/[your_username]`) |
| `[TAB]` | Press TAB to auto-complete |
| `head` | Show the 'head' (i.e. top) of a particular file |
| `nano` | Open/view a file using the 'nano' text editor |
