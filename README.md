# ONT Bioinformatics Practical

A bioinformatics practical for processing Oxford Nanopore Technologies (ONT) amplicon sequencing data, developed by the NHM Sequencing Facility.

## About

The practical is hosted at: https://nhm-sequencing-facility.github.io/ONT_bioinformatics_practical

It covers the processing and analysis of COI amplicon sequencing data generated on an Oxford Nanopore Technologies (ONT) platform, from raw reads through to taxon identification.

## Topics covered

1. Understanding and locating ONT amplicon sequence data
2. Generating initial sequence quality metrics
3. Visualising raw sequence quality
4. Quality control of sequence data
5. Visualising quality-controlled sequence data
6. Screening for contaminant sequences using Kraken2
7. Reference-based mapping
8. Generating a consensus sequence
8.1. Generating a consensus sequence through a clustering approach
9. Species validation through BLASTn
